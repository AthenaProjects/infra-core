# Athena Infra Core

Lightweight utility helpers and circuit-breaker tools for our server experiments.

[![TypeScript](https://img.shields.io/badge/TypeScript-5.x-blue?style=flat-square)](https://www.typescriptlang.org/)
[![Node.js](https://img.shields.io/badge/Node.js-22%2B-green?style=flat-square)](https://nodejs.org/)

### Features
- **Telemetry Buffer:** Low-overhead metric buffers for tracking server ticks and packet events.
- **Circuit Breaker:** Fail-fast wrapper to protect Minecraft server nodes from database and Redis lag.
